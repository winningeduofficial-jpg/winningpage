## 13. Open Questions (시안만으로 판단 불가)

1. **레이어명 vs 실제 내용 불일치** — `설문조사 결과` 라는 이름이지만 설문 문항이 없다. 이 프레임이 "설문 완료 후 결과 리포트"인지, 별도 결과 페이지 라우트인지 확인 필요.
2. **레이더 차트가 래스터 이미지** (`2226:2944`, image 237) — 응답에 따라 값이 달라져야 하므로 실제 구현에서는 차트 라이브러리로 동적 렌더링해야 한다. 축 순서/최대값(100 기준?)/그리드 링 개수/폴리곤 색·투명도 스펙 미확정.
3. **진행바 fill 폭 → 점수 매핑 규칙 불명** — 트랙 231px 기준 fill 68 / 75.209 / 87 / 99 / 134 / 190px. 100점 만점 선형이면 29.4 / 32.6 / 37.7 / 42.9 / 58.0 / 82.3점이나, 본문 언급 점수(예: 탐구 심화 35점, 활동 연계 48점)와 불일치. 정확한 스케일/최대값 확인 필요.
4. **바 색상 임계값 규칙 불명** — `#991e1e`(취약/우선 보완) / `#736123`(보완 필요·점검 필요) / `#1b5da0`(보통·상위·양호) 로 나뉘지만 점수 컷오프 기준 미정의.
5. **뱃지 라벨 체계** — `1순위`~`4순위` 다음에 `점검`, `유지` 가 오는데, 순위가 항상 4개 + 점검/유지 2개 고정인지, 6영역 중 동적 분류인지 불명.
6. **중복 레이어 다수** (§3.6) — 어느 세트가 최신인지 확인 필요. 현재 두 세트 내용이 동일해 시각 차이 없음.
7. **요약 카드 좌우 간격 불균등** — 19px / 18px. 20px 균등 의도인지 확인 필요.
8. **입결표 1·2행 라벨 중복** — 두 행 모두 `50% 컷(합격자 중위)`. 통상 `70% 컷` / `50% 컷` 이어야 할 것으로 보임.
9. **오타 다수 (원문 그대로 기록)** — `보완이 피요한 단계`(필요한), `힙격 가능성 예측`(합격), `건국대학교 경역학과`(경영학과), `가장 시급힌다`(시급하다). 수정 여부 디자이너 확인 필요.
