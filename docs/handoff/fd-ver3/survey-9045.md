## 10. 시안만으로 판단 불가한 항목 (Open Questions)

1. **조건부 노출 로직이 시안에 전혀 표기되지 않음.** Q4~Q8이 모두 동시에 펼쳐진 정적 상태로만 그려져 있다. 실제로는 최소 다음이 조건부일 것으로 추정되나 확인 필요:
   - Q6 "초근 모의고사 등급" 세트의 등급 범위(`1~9`)가 Q4(9등급제 / 5등급제 / 성취평가제) 선택에 따라 바뀌는지.
   - Q6 "전체 평균 및 과목별 평균" 세트의 과목 구성이 Q5(전 과목 / 국영수사과 / 국영수사 / 국영수과 …) 선택에 따라 달라지는지.
   - Q7 학기 필드 개수가 학년(1~3학년, 앞선 1~3번 문항으로 추정)에 따라 가변인지. 시안은 3학년 1학기까지 5칸 고정.
   - Q8 하위 칩("성적 변화가 가장 큰 과목")이 Q8 주 선택지에서 "아직 비교할 시험 결과가 부족해요"를 고르면 숨겨지는지.
2. **필수/선택 여부 표기가 없음.** `*` 마크나 "필수" 배지가 어디에도 없어 필수 여부를 시안에서 판단할 근거가 전무하다. (보조문구 `하나만 선택해 주세요.`는 선택 개수 제약이지 필수 표기가 아니다.)
3. **Q8 칩 블록의 선택 타입 불명.** 8개 칩 모두 라디오와 동일한 원형 아이콘을 쓰지만, "성적 변화가 가장 큰 과목"에 `여러 과목` 선택지가 있어 단일 선택인지 복수 선택인지 결정 불가. 별도 보조문구도 없다.
4. **선택/포커스/에러/비활성 상태 시안 없음.** 모든 선택지·입력 박스가 미선택(회색 보더 `#D7D7D7`) 단일 상태로만 그려져 있다. 선택 시 보더/배경/아이콘 색, 입력 포커스 링, 유효성 에러 표현 미정의.
5. **Q6 세트 A의 숫자(3.24 / 3.0 / 2.1 …)가 플레이스홀더인지 입력된 값인지 불명확.** 색상이 세트 B의 `1~9`(명백한 플레이스홀더)와 동일한 `#D7D7D7`이라 플레이스홀더로 보이나, 내용은 실제 값 형태다. Q7의 `4.10 / 3.68 …`도 동일 이슈.
6. **입력 필드의 실제 입력 방식 미정의.** `number` 텍스트 입력인지 셀렉트/스테퍼인지, 소수점 자릿수 제한(3.0 vs 3.24 vs 4.10 혼재), 허용 범위(등급 1~9 / 내신 1.00~9.00) 모두 미표기.
7. **잔여 문항 pill의 인터랙션 미정의.** `#D7D7D7` 배경 + 흰 텍스트는 비활성 버튼처럼 보이나, 클릭 가능한 "다음" 버튼인지 단순 안내 라벨인지 불명. 활성 상태 색상도 없다. 다음/이전/제출 버튼 자체가 프레임에 없다.
8. **진행률 게이지가 없다.** 스텝 배지 + 잔여 문항 텍스트만 존재. 상단 고정 프로그레스 바 필요 여부는 시안으로 판단 불가.
9. **Q1~Q3, Q9~Q19 시안이 이 프레임에 없다.** 카테고리 라벨이 `기본정보`/`성적입력` 두 종류만 나타나므로 전체 카테고리 체계와 문항 순서를 이 프레임만으로 알 수 없다.
10. **프레임 하단 224px 미사용 영역.** 루트 프레임은 4459인데 본문 `1889:9046`(4235) + 푸터 끝이 4235에서 끝난다. 4235~4459 구간 224px(14rem)의 의도(여백/잘린 요소/의도치 않은 프레임 크기)가 불명.
11. **페이지 배경 `#FBFAFA`는 스크린샷 픽셀 샘플링으로 얻은 값이다.** `1889:9046`/`1889:9081`은 `get_design_context` 응답이 토큰 한도(74,239자)를 넘어 fill을 직접 확인하지 못했다. 구현 전 Figma에서 재확인 권장.
12. **모바일/태블릿 브레이크포인트 시안 없음.** 1920 데스크톱 1종만 존재. 992px 카드 콘텐츠 폭, 100px 고정 입력 필드, 가로 7칸 그리드의 반응형 축소 규칙 미정의.
13. **카피 오타 확인 필요 (시안 원문 그대로 기재함).**
    - `초근 모의고사 등급` → `최근`으로 추정 (1889:9233)
    - `큰 변화 없이 정제되어 있어요` → `정체되어`로 추정 (1889:9353)
    - `사람마다 성적 변동이 큰 편이예요` → `편이에요`로 추정, 또한 문맥상 `과목마다`일 가능성 (1889:9363)
    - `전체 평균 및 과목별 평균 ` 끝 공백 1칸 (1889:9181)
14. **Code Connect 매핑 조회 불가.** 현재 Figma 시트 권한(Dev/Full seat 미보유)으로 `get_code_connect_map` 호출이 거부되었다. 디자인 시스템 컴포넌트 ↔ 코드 컴포넌트 매핑이 별도로 존재하는지 확인 필요.
