## 8. Open Questions (시안만으로 판단 불가)

1. **Q3 하위 그룹의 조건부 노출 로직** — 목표대학 입력(A) / 희망학과 입력(B) / 선택 이유(C) 3개 블록이 시안에는 항상 펼쳐진 상태로만 그려져 있다. 주 선택지 1~6 중 무엇을 고르면 어떤 블록이 나오는지 정의 필요.
2. **`1889:8939` 라벨 오탈자** — `희망 학과 또는 모집단위 `(끝 공백) 가 `1889:8933` 라벨과 중복. 선택지 내용상 "목표를 그렇게 정한 이유"가 맞아 보인다. 정확한 문구 확정 필요.
3. **선택 그룹 C의 단일/다중 선택 여부** — 아이콘이 다른 단일선택 칩과 동일하고, 그룹 헤더에 `하나만 선택해 주세요.` 같은 보조문구가 없다. single 인지 multiple 인지 확정 필요.
4. **Q1 `N수생` → Q2 분기** — `N수생` 선택 시 Q2(재학 중인 학교 유형)를 건너뛰는지, `해당 없음`을 자동 선택하는지, 그대로 묻는지.
5. **선택/포커스/에러 상태 디자인 부재** — 칩 selected 상태, 입력 필드 focus/filled/error 상태, 유효성 메시지가 시안에 없다.
6. **하단 바의 정체와 상호작용** — `16개 문항이 남았어요` 바가 (a) 단순 안내 배너인지 (b) 비활성 상태의 "다음/제출" 버튼인지 불명확. 활성 상태 색상·문구, 클릭 시 동작(다음 3문항 로드 vs 페이지 이동) 정의 필요.
7. **19문항 전체 페이징 구조** — 이 화면에 3문항이 있고 16문항이 남는다면 총 7페이지 구성인지, 스크롤 무한 로드인지, 각 페이지의 문항 수가 일정한지.
8. **필수/선택 표기 규칙** — `*` 같은 필수 표기가 전혀 없다. 모든 문항이 필수인지, 스킵 가능한 문항이 있는지.
9. **질문 텍스트 line-height 20px @ font-size 24px** — Figma 원값이 폰트보다 작다. 의도된 값인지, 웹에서는 1.4 등으로 보정해야 하는지 디자이너 확인 필요.
10. **푸터 하단 블록 폭 1925px / x=-2.5** — 1920 프레임보다 5px 넓게 삐져나와 있다. 시안 정렬 실수로 보이며 구현 시 100% 폭으로 처리할지 확인 필요.
11. **Q1/Q2 질문 문장 끝 마침표 불일치** — Q1 `현재 학년을 선택해 주세요`(없음) vs Q2 `현재 재학 중인 학교 유형을 선택해 주세요.`(있음). 표기 통일 여부.
12. **Q3 선택지 4번 `현재 성적으로 지원할 수 있을거 같아서`** — `있을거` 띄어쓰기 오탈자(`있을 것 같아서`). 원문 유지 여부 확인.
13. **반응형/모바일 시안** — 이 노드는 1920 PC 전용. 태블릿·모바일 브레이크포인트 시안 별도 확인 필요.
14. **Code Connect 매핑** — 플랜/시트 권한 부족으로 조회 불가. 코드 매핑 존재 여부 미확인.
15. **`#FBFAFA` 페이지 배경** — Figma 변수/스타일이 아니라 렌더된 PNG 픽셀에서 실측한 값이다. 디자인 상 정확한 fill 값 재확인 권장.
