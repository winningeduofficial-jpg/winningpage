## 5. 결과 리포트(`1889:12784`) 범위 포함 확인 — **포함 확정**

- A4-3 `2226:2907` (400,164) 1120×1584.9412841796875 · A4-4 `2226:3036` (400,1848.94) 동일 규격 · PDF 버튼 `2181:11685` 253×60 — **전부 헤더(0→64)와 푸터(3693.88→4285.88) 사이**에 위치.
- 즉 **3629.882568359375px 전 구간이 본문 = 이 브랜치 범위.**
- 단 **[B]/[C] 분리에 따라 1차는 "정적 렌더까지"**:

- **1차 착수 블로커 아님.** SPEC §4.7 "채점 규칙 확정 전 착수 불가"는 *기능* 한정이며, 디자인 구현은 시안에 표기된 값(예시 점수)을 하드코딩해 진행 가능.
