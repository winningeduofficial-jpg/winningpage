### 3.1 승계 (0729 확정, 재논의 금지)

1. 컨텐츠 폭: 전역 `max-w-content` = **72.75rem (1164px)**, `px-8` 포함 내부 1100px. 시안의 1100/1098/1112 폭은 이 토큰으로 해석.
2. px→rem 환산: 시안 문자값 ÷16, **소수점 원값 그대로**. 반올림·14px 하한 보정 전부 금지.
3. 섹션 수직 리듬: 각 섹션이 **자기 위 갭을 `pt`로 소유**, `pb=0`.
4. 헤더 **64px** (소비처 `pt-16`).
5. accent `#0B84FD` 는 Tailwind `text-accent` 토큰 사용 — **하드코딩 금지**.
6. 히어로 배경 Planet(보라 원, `2181:11088`)은 **코드에서 제외**. 시안에 존재하나 구현하지 않음.

### 5.1 현행 스키마 (REST 프로브 실측)

```
free_diagnosis_questions  id uuid, title, description, input_type, is_required, is_active, sort_order, question_key, created_at, updated_at
free_diagnosis_options    id, question_id uuid, label, program_ids text[], is_active, sort_order, question_key, created_at, updated_at
free_diagnosis_programs   id, title, badge, description, primary_button_text/link, secondary_button_text/link, icon, is_active, sort_order, created_at, updated_at
```

- `program_ids` = `text[]` (jsonb 아님). `programs.id` 에 FK 없음 — 코드가 dangling 을 필터.
- `input_type` 은 PG enum 아님 → 새 값 삽입 시 타입 에러는 없음. CHECK 제약 유무는 미확인.
- `question_key` 는 questions/options 양쪽에 실재하나 앱에서 **읽지도 쓰지도 않는 사표 컬럼**.
- `sql/` 에 free_diagnosis DDL **0건**, `supabase/migrations/` 디렉터리 자체 없음.

### 5.3 권장 결론

- **경로 A (권장, KISS)**: 3테이블 유지 + 컬럼 추가.
  `questions` += `category`, `page_no`, `placeholder`, `max_select`, `min_select`, `depends_on_question_id`, `depends_on_values text[]`, `dimension`, `config jsonb`
  `options` += `is_exclusive bool`, `score int`, `value text`(`question_key` 재활용)
  리커트 문장·그리드 셀은 `config jsonb` 에 배열로 수납. **관리자가 리커트 문장을 편집할 필요가 없다면 A로 충분.**
- **경로 B**: `free_diagnosis_question_items` 신설로 리커트 문장/그리드 셀 정규화. 관리자 편집이 필요하면 B.
- **어느 경로든 공통 전제**: `free_diagnosis_submissions` + `free_diagnosis_answers` **신설 필수.** 근거 — 리포트가 학생명·학년·진단완료일을 표시하고, PDF 재다운로드·결과 URL·5스텝 상태 보존이 전부 저장에 의존한다. 현재 저장이 0건이라 새 시안과 **정면 충돌**.
- **응답 저장 필요 여부: 필요 (필수).** 논쟁 여지 없음.
- `profiles` 에 **학년 컬럼 없음** (id/name/email/phone/school_type/school_name/gender/address/memo/role) → 리포트의 학년은 Q1 응답에서 가져와야 함.
- 착수 전 **현행 스키마 SQL 덤프를 `supabase/migrations/` 베이스라인으로 커밋** 권장.
