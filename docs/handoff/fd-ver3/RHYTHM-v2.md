## 0. 헤더 오프셋 모델 (모든 화면 공통 전제)

시안 3종(랜딩 `2162:1020`, 설문 `1889:8753`·`1889:9045`·`1889:10656`, 결과 `1889:12784`) 모두 **헤더가 본문 위에 오버레이된 형제 노드**다. 즉 시안의 "본문 상단 y좌표"는 **헤더 밴드를 포함한 페이지 최상단 기준값**이다.

수집 문서가 이미 이 모델을 명시한다 — `survey-10656.md:378`:

| 항목 | 값(px) | rem |
|---|---|---|
| 헤더 하단 ~ 본문 상단(타이틀) | **120 − 64 = 56** | 3.5 |

따라서 본 문서는 이 문서 자체의 관례를 승계하여 다음 공식을 표준으로 쓴다.

```
본문 최상단 pt  =  (시안 본문 상단 y)  −  (헤더 높이 H)
```

| 화면 | 시안 본문 상단 y | H=84 (현행) | H=64 (landing-renewal 머지 후) |
|---|---|---|---|
| 랜딩 히어로 (`2181:10903`) | 100px | **16px / 1rem** | 36px / 2.25rem |
| 설문 5화면 (`1889:8790` 외) | 120px | **36px / 2.25rem** | 56px / 3.5rem |
| 결과 리포트 (`2226:2907`) | 164px | **80px / 5rem** | 100px / 6.25rem |

두 헤더 높이에서 **차이는 정확히 20px 고정**이다.

### 0.1 구현 방식 — 한 줄 상수화

`fixed` 헤더이므로 본문 래퍼에 헤더 높이만큼 스페이서 padding 이 필수다. 스페이서와 섹션 pt 가 **같은 변수**를 참조하면 머지 시 한 줄만 바뀐다.

```css
/* src/index.css (또는 renewal 레이아웃 루트) */
:root {
  --wn-header-h: 5.25rem; /* 84px — landing-renewal 머지 시 4rem(64px) 한 줄만 교체 */
}
```

```jsx
{/* 본문 래퍼: 헤더 스페이서 */}
<main style={{ paddingTop: 'var(--wn-header-h)' }}>
  {/* 히어로: 시안 100px 총 오프셋에서 헤더 높이를 뺀 나머지 */}
  <section className="pt-[calc(6.25rem-var(--wn-header-h))]">
```

- 랜딩 히어로 `calc(6.25rem - var(--wn-header-h))`
- 설문 컨테이너 `calc(7.5rem - var(--wn-header-h))`
- 결과 리포트 `calc(10.25rem - var(--wn-header-h))` (164px = 10.25rem)

머지 시 변경 지점은 `--wn-header-h: 4rem` **1줄뿐**이며, 3개 화면이 자동으로 36 / 56 / 100px 로 복원된다.

### 0.2 ⚠ 결정 필요 — 히어로 16px

공식대로면 H=84 에서 히어로 아이브로우가 헤더 밑 **16px** 에 붙는다. 시안(H=64)의 36px 대비 44% 압축이며 3화면 중 가장 타이트하다. 두 안:

- **안 A (페이지 절대 정합, 위 공식 그대로)** — 히어로 16px. 페이지 총 높이가 시안과 동일. 문서 관례(`survey-10656.md:378`)와 일치.
- **안 B (헤더 아래 여백 보존)** — 히어로 36 / 설문 56 / 리포트 100 을 헤더 높이와 무관하게 고정. H=64 시 안 A와 완전히 동일해지므로 **머지 시 변경 0줄**. 대신 H=84 동안 페이지가 20px씩 길어진다.

권장: **안 A + `calc()` 상수화.** 상수 구조만 잡아두면 안 B로의 전환도 상수 1개 교체로 끝난다.

#### ⚠ 최종 CTA — pb=0 정책이 성립하지 않는 유일한 섹션

`2162:1193` 은 배경 `#172437` 밴드다. 앞 섹션의 pb 236 을 CTA 의 pt 로 흡수하면 **다크 밴드가 236px 더 길어져 시안과 달라진다**(473 → 709).

세 가지 처리안:
- **(권장) margin-top 으로 소유** — `mt-[14.75rem] pt-[8.8125rem] pb-[8.875rem]`. pb=0 정책의 취지(앞 섹션이 뒷 갭을 갖지 않음)를 유지하면서 밴드 실측 높이 473px 를 정확히 재현.

- (비권장) CTA `pt-[23.5rem]` — 밴드 높이가 시안과 어긋남.

같은 이유로 **배경색을 가진 섹션은 pb=0 정책의 구조적 예외**다. 현재 랜딩에서 해당하는 것은 최종 CTA 하나뿐이다.
