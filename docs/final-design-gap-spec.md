## 1. 개요

6개 섹션(히어로 / 합격생 / 서비스 / 멘토 / 학교리스트 / 공지사항)을 Figma 최종본과 대조한 결과:

| 섹션 | 갭 수 | high | medium | low | 비고 |
|---|---|---|---|---|---|
| 히어로 | 2 | 1 | 1 | 0 | 인디케이터 위치·스타일이 최대 이슈 |
| 합격생 | 0 | 0 | 0 | 0 | **완전 일치** — 수정 불필요 |
| 서비스 | 6 | 1 | 2 | 3 | 설명 줄바꿈이 최대 이슈 |
| 멘토 | 2 | 1 | 0 | 1 | 타이틀 정렬이 최대 이슈 |
| 학교리스트 | 3 | 0 | 1 | 2 | 행간 1건 + 에셋 diff 확인 |
| 공지사항 | 5 | 0 | 0 | 5 | 전부 미세 조정 |

이미 일치가 확인된 항목(합격생 전체, 각 섹션 matches)은 **재작업 금지** — 본 문서의 갭만 수정한다.

## 2. 공통(크로스 섹션) 이슈

### 2.1 콘텐츠 폭 — 전 섹션 1500px 통일 vs Figma 섹션별 그리드 ⚠️ 결정 필요 (5.1)

Figma 최종본은 섹션마다 콘텐츠 그리드가 다르다. 현재 구현은 확정 사항대로 **전 섹션 `max-w-[93.75rem]`(1500px) + px-8 통일**이다.

| 섹션 | Figma 그리드 | 현재(1500 통일) | 실질 차이 |
|---|---|---|---|
| 히어로 | x≈294.76, w≈1330.47 | 카드 969→약1046 / 321→약347 비례 확대 | 카드 스케일 차이 |
| 합격생 | x=280, w=1480 | 좌측 시작 ~242px | 약 38px (육안 식별됨) |
| 서비스 | x=280, w=1440 | 그리드 셀 473px 내 카드 449.5px 중앙 | 카드 폭 파생 결정 |
| 멘토 | x=280, w=1360 | 좌측 210px | 타이틀 정렬 기준에 영향 |
| 학교리스트 | x=200, w=1520 | 로고 총폭이 1500 안에 수렴 | **렌더 차이 0** |
| 공지사항 | x=240 | 좌 마진 ~242px | 사실상 일치 |

→ 섹션별 개별 갭으로 반복하지 않고 여기서 일괄 결정한다. **결정 전까지 폭 관련 수치는 수정 보류**, 폭과 무관한 갭(인디케이터·줄바꿈·행간 등)은 선행 가능.

### 2.2 통이미지 운영 방식 유지 (결정 14 재확인)

Figma 최종본은 히어로 좌측/우측 카드·멘토 카드를 텍스트/이미지 레이어 분리 구조로 갖고 있으나, 확정 사항은 **통이미지(텍스트 포함) 관리자 업로드**다. 레이어 분리 추종은 기본적으로 하지 않는다 (번복 시 5.2·5.3 참조).

## 6. 작업 순서 제안

의존성: 5.1(폭)·5.6(줄바꿈 방식) 결정이 선행되어야 하는 항목이 있으므로, **결정 무관 항목부터 착수**한다.

### 0단계 — 결정 수집 (사용자)
- 5.1 콘텐츠 폭, 5.6 줄바꿈 구현 방식 — **최우선 2건** (high 갭의 선행 조건)
- 나머지 5.2~5.10은 권장안 일괄 승인 가능

### 1단계 — 에셋 확인 (병렬 가능)
- 학교리스트 image 331~340 다운로드 → 기존 14개 PNG diff → 교체/유지 판정 (4절 #1)
- Figma 인스펙트 실측 3건: 서비스 설명 폰트 크기·색상, 공지 배경/중요 배지 토큰 (low·확신 낮음 갭의 확정용)

### 2단계 — 레이아웃 (high + medium)
1. **히어로 인디케이터 카드 밖 이동 + 스타일 교체** (high)
2. **멘토 타이틀 좌측 정렬** (high — 5.1 결정 반영)
3. 히어로 세로 여백 50→100px (medium — 인디케이터 이동 후 하단 재확인)
4. 학교리스트 행간 gap-16→gap-5 (medium)
