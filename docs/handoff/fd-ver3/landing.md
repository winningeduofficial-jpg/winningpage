## 9. Open Questions (시안만으로 판단 불가)

1. **에셋 URL 중복** — `2162:1147`(Lock/Body)과 `2240:4597`(맥북 화면 캡처)이 **동일한 asset id** `80e317ee-40ca-4667-935b-f32ce27e9a08`로 반환됐다. MCP 응답 그대로지만 물리적으로 다른 이미지여야 한다. 다운로드 후 실제 바이트를 확인하고, 어긋나면 각 노드를 개별 `get_design_context`로 재추출 필요.

2. **히어로 설문 캡처(`image 224`)의 정체** — 래스터 이미지라 문항 원문 추출 불가. 실제 설문 1문항을 렌더링한 라이브 목업으로 구현할지, 이미지 그대로 쓸지 미정. 이미지로 간다면 **원본 해상도(retina 2x) 확보** 필요.

3. **맥북 화면 캡처(`2240:4597`)** — 결과 화면 표 + 서술형 블록이 768×478 래스터로 박혀 있어 텍스트 판독 불가. 결과 화면 실물 스크린샷으로 교체할지, 시안 이미지를 그대로 쓸지 확정 필요.

4. **히어로 하단 클리핑 의도** — `2181:10899`(h=875)가 부모 `2181:10898`(h=750)보다 125px 크고 `overflow: clip`. 브라우저 목업 하단이 잘려 나가는 것이 **의도된 연출**인지, 시안 정리 미완인지 확인 필요. 잘림을 유지한다면 반응형에서 어떤 비율로 잘려야 하는지도 미정.
