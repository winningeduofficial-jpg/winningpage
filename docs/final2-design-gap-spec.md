### 3.2 콘텐츠 폭 1500px 통일 유지 (1차 결정 5.1 승계)

신규본도 섹션별 그리드가 다르지만(히어로 1330 / 합격생 1480 / 서비스 1440 / 멘토·공지 1520·1440) **전 섹션 `max-w-[93.75rem]`(1500px) + px-8 통일** 결정을 그대로 유지한다. 이로 인한 좌측 시작 x 차이(합격생 280→242, 서비스 280→242, 멘토 200→230, 히어로 카드 969→1048 비례 확대)는 **기지(旣知) 편차이며 갭이 아니다.**

### 3.3 통이미지 운영 방식 유지 (결정 14 승계)

히어로 좌/우 배너, 멘토 카드 22장은 **텍스트 포함 통이미지 + 관리자 업로드** 방식을 유지한다. 신규본의 텍스트 위치 변경(히어로 +19px)·배색 변경(멘토 카드)은 **코드가 아니라 에셋 재추출로 해결**한다.
