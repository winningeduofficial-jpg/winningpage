## 8. 디자인 토큰 (`get_variable_defs` 결과)

```json
{
  "01": "#525252",
  "텍스트": "#808080",
  "헤더": "#4d4d4d"
}
```

- 이 프레임에서 실제 변수로 바인딩된 값은 위 3개뿐이다.
- `#D7D7D7`, `#F9FAFB`, `#FBFAFA`, `#013262`, `#F5F5F5` 는 **raw hex** 로 하드코딩되어 있다 (변수 미연결).
- spacing / radius / typography 토큰은 존재하지 않는다.

## 9. Open Questions (시안만으로 판단 불가)

1. **선택 상태(selected/hover/focus) 디자인 없음.** 옵션칩·셀렉트 모두 미선택 상태만 존재. 선택 시 border/bg/아이콘 색상, 라디오 채움 형태를 알 수 없다.
2. **CTA 활성 색상 없음.** `진단 결과 보기` 버튼이 `#D7D7D7` 비활성만 그려져 있다. 활성 배경(브랜드 `#013262` 추정)과 hover/press 상태 확인 필요.
3. **스텝 칩/카테고리 라벨이 전부 비활성 톤(`#D7D7D7` 배경, `#808080` 숫자)** 이다. 답변 완료/현재 문항 등 상태별 색상 정의 필요.
4. **진행바(progress) 부재.** 19문항 중 15~19를 표시하는 화면인데 진행률 UI 가 없다. 이전 페이지 프레임(예: `1889:8753`, `1889:9866`)에도 없는지, 별도 컴포넌트인지 확인 필요.
5. **페이지 분할 규칙 불명.** 이 프레임이 Q15~Q19 를 담고 있으나 "이전" 버튼이 없다. 단일 롱스크롤인지 스텝 페이지네이션인지, 뒤로가기 동선이 무엇인지 미정.
6. **Q15 계단식 종속 로직 미정.** 대학 → 학과 → 전형 유형 → 세부 전형명이 실제로 종속 필터링되는지, 선행 필드 미선택 시 후행 필드가 disabled 인지 시안에 표기 없음.
7. **Q17 질문 문구의 조건부성.** `학생부종합 준비 상태는…` 이 Q15 의 전형 유형에 따라 문구가 바뀌는지(예: 논술전형이면 다른 문항) 불명.
8. **필수/선택 여부 표기 없음.** 어떤 문항도 `*` 등 필수 마크가 없다. CTA 가 비활성 상태로 그려진 것으로 보아 전 문항 필수일 가능성이 있으나 확정 불가.
9. **Q19 입력 제약 미정.** 최소/최대 글자수, 카운터, 멀티라인 여부(높이 105 고정 vs auto-grow) 정의 없음.
10. **문항 제목 line-height 20px 문제.** font-size 24px 에 line-height 20px 이 걸려 있고 텍스트 박스 높이만 40px 다. 의도된 값인지, 디자인 툴 아티팩트인지 디자이너 확인 필요. 2줄로 넘어가는 긴 문항(Q19 는 708px 폭 1줄)에서 어떻게 줄바꿈되는지 정의 없음.
11. **반응형/모바일 브레이크포인트 없음.** 1920 고정 시안만 존재. 옵션칩이 hug 폭 + 수동 줄바꿈(행 프레임 분리)으로 배치되어 있어 좁은 폭에서의 재배치 규칙이 정의되지 않았다.
12. **페이지 배경 `#FBFAFA` 는 렌더 픽셀 샘플값.** design context 에서 배경 fill 이 노출되지 않아 다운스케일된 PNG(1036px)에서 플랫 영역을 샘플링해 얻었다. 정확한 fill 은 Figma 인스펙터로 재확인 권장.
13. **Code Connect 매핑 확인 불가.** 시트/플랜 제한으로 `get_code_connect_map` 호출이 거절되어 기존 코드 컴포넌트 매핑 존재 여부를 알 수 없다.
