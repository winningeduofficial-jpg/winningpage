1. **페이지 배경색 선언값** — 렌더 샘플은 `#FBFAFA`(251,250,250). Figma 원본 노드(1889:9491 / 1889:9492)의 fill 선언값을 확인해야 함. `#FAFAFA` 가능성 있음.

3. **선택(active/checked) 상태 시안 부재** — 라디오·체크박스 선택 시 색상/아이콘, 선택된 선택지 행의 border·배경 변화가 정의되어 있지 않음.

5. **필수 응답 여부 / 검증 에러 UI** — 필수 표시(별표)나 미응답 시 에러 메시지 시안 없음.
6. **Q10 "특별히 큰 어려움은 없어요"(1889:9795) 배타 선택 여부** — 선택 시 나머지 12개 해제되는지 명시 없음.
